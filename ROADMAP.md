# Najumi Cloud Roadmap

Infrastructure ecosystem roadmap for Najumi Cloud developed by Najumi Tech.

---

# Vision

Najumi Cloud is being developed as a modern infrastructure ecosystem focused on deployment automation, runtime infrastructure, networking systems, storage services, and scalable developer platforms.

The roadmap reflects the long-term engineering direction of the ecosystem and planned infrastructure expansion across multiple cloud product categories.
