# Infrastructure Roadmap

Long-term infrastructure direction for the Najumi Cloud ecosystem.

---

# Introduction

Najumi Cloud is being developed as a modular cloud infrastructure ecosystem by Najumi Tech.

The platform roadmap focuses on gradually expanding from application deployment infrastructure toward a broader integrated cloud services environment for developers, startups, engineering teams, and scalable digital applications.

The roadmap is designed around:
- infrastructure scalability
- ecosystem interoperability
- operational simplicity
- developer-focused workflows
- production-ready infrastructure systems

---

# Current Infrastructure Stage

The platform is currently focused on foundational deployment infrastructure and runtime orchestration systems.

Implemented systems currently include:

- authentication infrastructure
- project management
- service management
- deployment orchestration
- GitHub deployments
- ZIP deployments
- runtime provisioning
- deployment logs
- reverse proxy routing
- subdomain provisioning
